Generate your first evidence package

The evidence package is the part your assessor actually asks for: one folder per control holding the finding, a remediation script, a direct console link and a guide naming the screen to screenshot.

# Scan, then package the evidence ./auditkit-pro scan -provider aws -framework soc2 ./auditkit-pro evidence-package -framework soc2 -output ./soc2-evidence.zip ✓ Evidence package generated successfully!
